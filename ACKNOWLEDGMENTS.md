# Acknowledgments

AURA Hub is built with open-source tools and a few focused services. Thanks to
the projects below and to everyone who reports issues, reviews changes, or
improves the documentation.

## Core tooling

- [Flutter](https://flutter.dev) and [Dart](https://dart.dev) — UI toolkit and language
- [flutter_riverpod](https://pub.dev/packages/flutter_riverpod) — state management
- [go_router](https://pub.dev/packages/go_router) — routing
- [crypto](https://pub.dev/packages/crypto) — hashing and PBKDF2
- [timezone](https://pub.dev/packages/timezone) and [intl](https://pub.dev/packages/intl) — time/date handling
- [flutter_markdown](https://pub.dev/packages/flutter_markdown) and [markdown](https://pub.dev/packages/markdown) — Markdown rendering
- [ffi](https://pub.dev/packages/ffi) — Windows native interop

## Local services and platform APIs

- [psutil](https://github.com/giampaolo/psutil) — Windows host telemetry
- Windows Credential Manager — local integration token boundary
- [Ollama](https://ollama.com) — optional local AI provider on loopback
- [Groq](https://groq.com) — optional user-configured OpenAI-compatible provider

## Project references

- [Contributor Covenant](https://www.contributor-covenant.org) — code of conduct
- [Keep a Changelog](https://keepachangelog.com) — changelog format
- [Semantic Versioning](https://semver.org) — version format

## Hardware target

- Waveshare ESP32-S3 Touch LCD 4.3B — future AURA panel target. Hardware has not
  been ordered and no device transport exists in this build.

## Security reporters

If you privately report a vulnerability and would like credit, mention it in
your report. Credit is optional and never required for a valid report.
